# Manifest

Official macOS installers and the update feed for Manifest, a music project library
by Airscape Records.

[Download the latest release](https://github.com/iamcaptaine/Manifest-Releases/releases/latest)

Apple silicon; macOS 13 or later. Quit Manifest before running the PKG installer.
These 0.x builds are development releases with unsigned, unnotarized installers.
macOS handles installation and any required approval prompts.

In Manifest, use **Manifest → Check for Updates…** or **Options → Check for
Updates…**. Review the notes, choose **Download Update**, then **Show Installer**
to find the verified PKG in Downloads. Automatic launch checks can be disabled
in the same panel; downloads and installation remain your choice.

This repository distributes installers, SHA-256 checksums, and release notes.
The application source is developed privately.
